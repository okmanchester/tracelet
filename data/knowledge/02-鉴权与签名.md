# 鉴权与签名

## 鉴权要素

所有接口请求必须携带以下鉴权信息：

| 字段 | 位置 | 说明 |
| --- | --- | --- |
| `X-Api-Key` | Header | 应用创建时生成的 API Key，用于标识调用方身份 |
| `X-Timestamp` | Header | 当前 Unix 秒级时间戳，与服务端时间偏差不得超过 5 分钟 |
| `X-Sign` | Header | 按下方算法计算出的签名，小写十六进制 |
| `Secret Key` | 不传输 | 仅保存在客户服务端，用于计算签名，**不得下发到前端或公开仓库** |

API Key 与 Secret Key 在控制台应用详情页获取。Secret Key 仅在创建时完整展示一次，遗失需重新生成。

## 签名算法五步

1. **收集参数**：将请求 body 中的业务参数（不含 `sign` 字段）与 `api_key`、`timestamp` 合并为待签名参数集合。
2. **字典序排序**：按参数名的 ASCII 字典序升序排列，区分大小写。
3. **拼接字符串**：按 `key=value` 格式用 `&` 连接，跳过空值（`null`、空字符串），value 不做 URL 编码。
4. **追加密钥**：在拼接串末尾追加 `&secret=你的Secret Key`。
5. **计算摘要**：对最终字符串做 HMAC-SHA256，输出小写十六进制字符串，作为 `X-Sign` 发送。

Python 参考实现：

```python
import hashlib
import hmac
import time


def build_sign(secret: str, api_key: str, params: dict) -> tuple[str, str]:
    ts = str(int(time.time()))
    data = {**params, "api_key": api_key, "timestamp": ts}
    raw = "&".join(f"{k}={data[k]}" for k in sorted(data) if data[k] not in (None, ""))
    raw += f"&secret={secret}"
    sign = hmac.new(secret.encode("utf-8"), raw.encode("utf-8"), hashlib.sha256).hexdigest()
    return ts, sign
```

## 时间戳与时钟同步

`X-Timestamp` 必须为秒级（不是毫秒）。服务端允许 5 分钟偏差，超出窗口按签名错误处理，返回 401 `SIGN_INVALID`。建议服务器开启 NTP 时间同步。

## 401 鉴权失败排查

接口返回 HTTP 401 时，先用响应中的 `request_id` 查调用日志确认错误码，再按下表处理：

| 错误码 | 含义 | 常见原因 | 处理方式 |
| --- | --- | --- | --- |
| `AUTH_KEY_EXPIRED` | API Key 已过期 | Key 超过有效期 | 控制台重新生成 Key，更新服务端配置后重试 |
| `AUTH_KEY_INVALID` | API Key 无效 | Key 复制不完整、被禁用、格式错误 | 核对完整 Key，确认状态为启用，使用有效 Key 重试 |
| `SIGN_INVALID` | 签名错误 | 参数排序、拼接、Secret 或时间戳错误 | 按签名算法逐项复核后重算签名 |

## SIGN_INVALID 常见原因

1. **未参与签名的参数**：签名只覆盖已提交的业务参数，新增或漏传参数会导致客户端与服务端拼串不一致。
2. **排序方式错误**：必须按参数名 ASCII 字典序，不能按提交顺序或字母表以外的规则。
3. **Secret 用错**：使用了其他应用、测试环境或旧版本的 Secret。
4. **时间戳偏差**：服务器时间与标准时间相差超过 5 分钟。
5. **值被改写**：网关或中间件对参数值做了 URL 编码、类型转换或重新序列化。建议使用实际发送的值参与签名。
6. **大小写问题**：签名结果需为小写十六进制，部分语言默认输出大写。

## 安全建议

- Secret Key 通过环境变量或密钥管理服务注入，禁止写入代码仓库与前端。
- 按环境、按业务线使用独立应用与 Key，便于审计与快速轮换。
- 定期轮换 Secret，轮换时先双 Key 并存再下线旧 Key，避免业务中断。
- 开启 IP 白名单后，将服务器出口 IP 加入白名单，否则返回 `IP_NOT_ALLOWED`。
