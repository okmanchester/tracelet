## 试用前必须补齐的证据

- 同业务请求重复提交、日志失败和提交后超时不产生重复工单；未知结果可查询，回复不声称未成功的动作。
- Agent 全部/部分失败、无命中、证据不足、建单失败和主动转人工都具有确定结果，建单与会话模式关系明确。
- Redis 清空/过期可恢复允许使用的历史；人工消息进入后续上下文；附属故障不丢失已提交结果。
- 多标签页、重复发送、实体并发更新和中途接管可确定复现，过时 AI 结果不违反接管决定。
- 密钥过期与统计上下界、时区和跨日行为符合真实运行含义；演示时钟不改变正常路径。
- 浏览器失败、中断和正常完成可区分，已提交结果能从会话查询；真实依赖演练使用合成数据。
